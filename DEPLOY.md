# 📖 DEPLOY.md — развёртывание max-news-bot-omsu

Инструкция для человека без опыта администрирования. Всё, что нужно, —
сервер или компьютер с Linux (или Windows/Mac с Docker) и ~10 минут времени.

---

## 1. Что понадобится

| Что | Где взять |
|---|---|
| Сервер/ПК с интернетом | VPS, Proxmox-контейнер, домашний ПК — что угодно |
| Docker | ставится автоматически по инструкции ниже |
| Токен бота MAX | создаётся в MAX (шаг 2) |
| Канал MAX | создаётся в MAX (шаг 3) |
| VK-паблик (по желанию) | ваш паблик; сервисный ключ — шаг 4 |

---

## 2. Создайте бота в MAX

1. Откройте мессенджер MAX.
2. Создайте бота (в приложении MAX: раздел создания ботов / чат с платформой ботов —
   у каждого бота есть свой токен).
3. Скопируйте **токен** — он понадобится при установке.

> Токен — это секрет. Никому его не показывайте: кто знает токен — управляет ботом.

## 3. Создайте канал и добавьте бота

1. В MAX создайте **канал** (например, «Новости города»).
2. Добавьте в канал вашего бота (как участника/администратора).
3. Напишите боту в этот канал: `/start` — он ответит:
   ```
   Привет! Я бот новостей 🤖
   📢 Этот чат: -123456789012345
   ```
   Число после «Этот чат:» — это **ID канала**. Запишите его (со знаком «-»).

## 4. VK: сервисный ключ (только если нужен VK-паблик)

1. Откройте https://dev.vk.ru → создайте/выберите мини-приложение.
2. Раздел **Разработка → Ключи доступа**.
3. Скопируйте **Сервисный ключ** (токен приложения).
4. Домен паблика — это адрес без `vk.com/`, например: `gorodtavda`.

## 5. Установка

Подключитесь к серверу по SSH и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/evgeny-tvd/max-news-bot-omsu/main/install.sh | bash
```

Если Docker не установлен — скрипт подскажет:
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# перезайдите в SSH и повторите установку
```

Мастер задаст вопросы:
- **Токен бота** — из шага 2;
- **ID канала** — из шага 3;
- **VK-паблик и ключ** — из шага 4 (можно пропустить, если не нужен);
- **Канал предупреждений** — ID публичного канала MAX (например, РСЧС региона;
  можно пропустить);
- **Интервал опроса** — по умолчанию 60 секунд.

## 6. Проверка

```bash
docker compose ps          # STATUS: Up / healthy
docker compose logs -f     # «Новых постов нет…» — всё работает
```

> **Важно про первый запуск:** бот запоминает последний пост/сообщение источника
> и **не публикует старые**. Новые новости начнут приходить после их публикации
> в источнике. Это сделано специально, чтобы канал не засорялся архивом.

## 7. Частые вопросы

**Бот не отвечает на /start?**
Добавьте бота в канал правильно (шаг 3), подождите 1–2 минуты после запуска.
Смотрите логи: `docker compose logs -f`.

**Хочу добавить второй источник позже.**
Отредактируйте `.env` (он в той же папке, что и docker-compose.yml):
```bash
nano .env        # добавьте VK_DOMAIN=… / VK_TOKEN=… / RSCH_CHAT_ID=…
docker compose up -d --force-recreate
```

**Как обновить бота?**
```bash
docker compose pull && docker compose up -d
```

**Где хранится состояние (какие посты уже отправлены)?**
В папке `state/` рядом с docker-compose.yml. Удалять не нужно — иначе бот
«забудет» отправленное.

**Хочу мгновенные команды (webhook) — у меня есть домен.**
В `.env` задайте:
```
POLLING=false
WEBHOOK_URL=https://ваш-домен/webhook
WEBHOOK_SECRET=<длинный случайный набор символов>
```
Направьте домен на порт 8080 контейнера (nginx/Caddy с HTTPS-сертификатом).
Long Polling при этом должен быть выключен: MAX не допускает оба режима сразу.

## Не работает? Полезные команды

```bash
docker compose logs --tail=50      # последние ошибки
docker compose restart             # перезапуск
docker compose down && docker compose up -d   # полный перезапуск
```

Если ошибка непонятна — скопируйте вывод `docker compose logs --tail=50` и
покажите тому, кто настраивает бота.
