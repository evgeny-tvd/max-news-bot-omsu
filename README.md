# 🤖 max-news-bot-omsu

Универсальный бот-репостер новостей для мессенджера **MAX**. Подходит органам
местного самоуправления (ОМСУ) и любым организациям: бот берёт новости из
VK-паблика и/или публичного канала MAX и автоматически публикует их в ваш канал.

- 📰 **Источник 1 — VK-паблик**: посты со стены (текст + фото + видео), как авторские
- ⚠️ **Источник 2 — канал MAX**: предупреждения/новости публичного канала
  (например, РСЧС вашего региона) — читается даже без членства бота
- 🖼️ Медиа: до 10 фото, видео до 30 минут (через yt-dlp), файлы до 200 МБ
- 🚀 **Установка одной командой**, без домена и HTTPS — Long Polling по умолчанию
- 🐳 Работает в Docker на любом сервере/ПК с интернетом

## Быстрый старт (~10 минут)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/evgeny-tvd/max-news-bot-omsu/main/install.sh)
```

Мастер спросит: токен бота MAX, ID вашего канала, VK-паблик (по желанию),
канал предупреждений (по желанию) — и запустит бота.

> Не знаете ID канала? Добавьте бота в канал и напишите ему `/start` —
> бот ответит «📢 Этот чат: …».
>
> ⚠️ Запускайте именно через `bash <(curl …)`, а не `curl … | bash` —
> иначе мастер не сможет прочитать ваши ответы (stdin занят скриптом).

Подробная инструкция — в [DEPLOY.md](DEPLOY.md).

## Как это работает

```
[VK-паблик] ──wall.get──▶  ┌─────────────────────┐
[Канал MAX] ──get_messages─▶ │  бот (Long Polling) │──▶ Ваш канал MAX
                            └─────────────────────┘
```

- Бот опрашивает источники каждые `NEWS_INTERVAL` секунд (по умолчанию 60).
- При первом запуске запоминает последний пост/сообщение — **старые не шлёт**.
- Дедупликация: VK — по id поста, канал MAX — по `mid`.
- Апдейты от MAX (команды) — через Long Polling: нужен только **исходящий** интернет.

## Команды бота

`/start` — приветствие и ID этого чата · `/news` — последние новости VK ·
`/news_now` — проверить VK сейчас · `/rsch_now` — проверить канал предупреждений ·
`/time`, `/date`, `/echo <текст>`

## Настройка (файл `.env`)

| Переменная | Обязательна | Что это |
|---|---|---|
| `MAX_BOT_TOKEN` | ✅ | токен бота MAX |
| `TARGET_CHAT_ID` | ✅ | канал, куда репостить |
| `VK_DOMAIN`, `VK_TOKEN` | ✅ | VK-паблик-источник (ядро репостера; сервисный ключ dev.vk.ru) |
| `RSCH_CHAT_ID` | встроен* | публичный канал-источник (по умолчанию РСЧС Свердловской обл.) |
| `NEWS_INTERVAL` | — | интервал опроса, сек (60) |
| `POLLING` | — | `true` — Long Polling (по умолчанию); `false` — webhook |
| `ADMIN_CHAT_IDS` | — | личные чаты, откуда можно запускать `/news_now`, `/rsch_now` (через запятую); по умолчанию — только из канала |
| `TZ` | — | часовой пояс (Asia/Yekaterinburg) |

Полный список — в [.env.example](.env.example).

## Webhook-режим (продвинутый)

Если у вас есть домен с HTTPS — можно включить мгновенную доставку команд:
`POLLING=false`, задайте `WEBHOOK_URL` и `WEBHOOK_SECRET`, направьте домен на порт 8080.
См. раздел в [DEPLOY.md](DEPLOY.md).

## Разработка

```bash
pip install -r src/requirements.txt -r requirements-dev.txt
python -m pytest tests/ -q        # тесты
python -m src.bot                 # локальный запуск (нужен .env)
```

Сборка образа: GitHub Actions по тегам `v*` → `ghcr.io/evgeny-tvd/max-news-bot-omsu`.
